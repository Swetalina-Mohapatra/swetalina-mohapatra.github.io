# Swetalina Mohapatra | Portfolio & Dossier

A clean, responsive, and performance-optimized digital portfolio showcasing academic credentials, industrial workforce research, people analytics toolsets, and continuous professional certifications.

🌐 **Live Website:** [https://swetalina-mohapatra.github.io/](https://swetalina-mohapatra.github.io/)

## 📌 Overview

This repository hosts the source code and static assets for Swetalina Mohapatra's professional portfolio. Built with modern, lightweight HTML5, CSS3, and vanilla JavaScript, the portfolio serves as an executive profile for postgraduate management admissions (MBA/PGDM) and corporate People Operations / HR roles.

---

## 🌟 Key Highlights & Sections

- **Hero & Executive Positioning:** Immediate clarity on domain expertise, graduating class, and core competencies across Strategic HRM and AI workflows.
- **Academic Foundation & Profile:** Academic background at Sambalpur University with an articulated career objective targeted at graduate business programs.
- **Industrial Research Case Study (Tata Steel Meramandali):** Grounded fieldwork and analysis on *“A Study on Upskilling of Contract Workforce”*, featuring verifiable completion credentials, gap diagnoses, and actionable training frameworks.
- **Skills & Capability Pillars:**
  - *Strategic HR & Talent Operations:* Training Needs Analysis (TNA), workforce upskilling, competency mapping, employee engagement, and IHRM.
  - *People Analytics & Quantitative Tools:* Advanced MS Excel (data modeling & pivot tables), HR dashboards, and metrics reporting.
  - *AI Workflows & Digital Productivity:* AWS Prompt Engineering, MS 365 Copilot, visual SOP creation, and AI workflow automation.
- **Verified Credentials Grid:** Interactive gallery with category filtering (`All`, `AI & Digital`, `HR & Management`, `Business & Finance`) and a responsive modal lightbox for 10+ industry certifications (AWS, HP LIFE, LinkedIn Learning, Coursera/IndiaAI, IBM, Bajaj Finserv).
- **Direct Engagement & Downloadables:** 1-click access to the updated resume (`assets/resume.pdf`), LinkedIn, and direct email communication.

## 🛠️ Technology Stack & Libraries

- **Markup & Styling:** Semantic HTML5, Vanilla CSS3 (CSS Grid, Flexbox, Custom Variables).
- **Typography & Icons:** [Google Fonts (Inter)](https://fonts.google.com/specimen/Inter), [FontAwesome 6.5](https://fontawesome.com/).
- **Animations:** [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/).
- **Privacy-First Analytics:** [GoatCounter](https://www.goatcounter.com/) & Google Analytics 4 (`gtag.js`).
- **Deployment:** GitHub Pages (Automated HTTPS hosting).

## 🚀 Local Development Setup

To run or test this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/swetalina-mohapatra/swetalina-mohapatra.github.io.git
   cd swetalina-mohapatra.github.io
   ```

2. **Run a local server:**
   Using Python:
   ```bash
   python -m http.server 8000
   ```
   Or using VS Code Live Server extension.

3. **Open in browser:**
   Navigate to `http://localhost:8000` to view the live site locally.
